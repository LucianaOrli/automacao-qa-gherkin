# 💎 Auditoria de Integridade e Automação ATS (Lux by Or)

Desenvolvimento de framework **BDD (Gherkin/Python)** para auditoria de fluxos em plataformas de recrutamento.

### 🛠️ Tecnologias:
* **Playwright** (Navegação de alta performance)
* **Pytest-BDD** (Cenários em linguagem natural)
* **Linux/Bash** (Infraestrutura e Automação)
* **Coverage** (Garantia de 100% de proteção do código)

### 📊 Resultados:
* **Redução de 95%** no tempo de preenchimento de formulários.
* **Mapeamento de conformidade LGPD** e auditoria de vieses de IA.
